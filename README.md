# Oduwa iOS (Objective-C)

An open-source Objective-C iOS reference application for the **Oduwa Coin** project. It fetches and displays real-time exchange rates between Oduwa Coin, major cryptocurrencies, and fiat currencies (such as USD and other international currencies).

## Features

- **Real-Time Exchange Rates:** Displays live conversion rates for Oduwa Coin against USD, other fiat currencies, and cryptocurrencies.
- **Lightweight Native Implementation:** Built in pure Objective-C without heavy external dependencies, making it easy to inspect, run, and extend.
- **Ready-to-Run Xcode Project:** Includes a complete `Oduwa.xcodeproj` setup for quick local testing.

## Requirements

- **macOS** with **Xcode** installed (Xcode 12 or later recommended)
- **iOS Simulator** or a physical iOS device
- Active internet connection to fetch live exchange rate data

## Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd Oduwa
   ```

2. **Open in Xcode:**
   Double-click `Oduwa.xcodeproj` or run:
   ```bash
   open Oduwa.xcodeproj
   ```

3. **Run the project:**
   - Select your target **iOS Simulator** (e.g., iPhone 15) from the Xcode toolbar.
   - Press **`Cmd + R`** or click the **Run (▶)** button.
